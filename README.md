# 本地独立版：无需后台服务器

这是浏览器运行的轻量可交互静态小网页，不是后台服务或 App。

## 直接使用
1. 在手机“下载”目录找到 **梦境织补屋.html**，选择支持 JavaScript 的浏览器打开，不要仅用文件预览器。完整路径：`/sdcard/Download/梦境织补屋.html`。
2. CSS、脚本和 SVG 已内嵌，不需要启动 Python、保持后台进程或连接旧网址；使用者无需安装开发工具。
3. 在“收藏 → 把小店好好收起来”可导出 JSON 备份或导入备份。导入会覆盖当前进度与备份中有效声音设置，务必先导出当前进度。
4. 进度保存在当前浏览器本地。换浏览器、改路径、移动文件或清理浏览器数据后，不保证自动继承。存储不可用时页面会提示；关闭前请导出，导入则需要可写本地存储。
5. 导出提示仅表示已请求下载，请自行确认文件真的保存；某些文件预览器不支持下载或选文件。

## 从旧网址迁移
如旧进度仍在 `http://127.0.0.1:8765/`，先临时保留旧静态服务，刷新打开新版收藏页，导出备份；再打开本地 HTML 导入。不要预设旧网址与文件共享存档。正常使用独立 HTML 不需要旧服务，本轮没有擅自停止它。

## 开发与构建（非使用前提）
源码保留在 `/sdcard/Download/dream-mender`，目录内也有 `梦境织补屋-直接打开.html`。修改源码后执行：
```sh
cd /sdcard/Download/dream-mender
python3 build-local.py
cp 梦境织补屋-直接打开.html /sdcard/Download/梦境织补屋.html
```
生成器会内嵌静态与动态图片并检查残留外部资源引用。日常打开网页不运行此命令。开发时仍可选用静态 HTTP 服务器，但不是交付依赖。

## 验证范围
当前 WebView 的 file:// 打开、初始与动态图片、接梦、导出 JSON 内容、导入确认刷新恢复、取消/Escape/无效文件保护、320px 无横向溢出已验证。文件管理器 content://、完整浏览器系统下载/选文件、多浏览器及真实声音听感尚待实机验收。详见 [LOCAL-REPORT.md](LOCAL-REPORT.md)。
