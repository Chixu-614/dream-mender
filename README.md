# 梦境织补屋 🌙

## [✨ 点击这里，走进梦境织补屋](https://chixu-614.github.io/dream-mender/)

和小眠一起，开一间修补好梦的小店。

听客人讲述心愿，找回散落的光，把梦一点点补好。忙完了就摸摸搭档的头、一起接星星，再把明信片和留言好好收起来。不计时，做错也不扣分，慢慢来就好。

### 在小店里做些什么

- **接待带着梦来的客人**：十五场梦，包含寻找光片、顺序点亮和明牌配对等小谜题。
- **随时歇一歇**：修梦可以暂存，回来继续；打烊或刷新也能保留任务进度。
- **和小眠相处**：摸头、喂点心、接星星，也能调整伙伴性格与形象。
- **收藏日常**：添置固定位置的家具，收集修梦明信片和客人留言。

适合手机竖屏游玩。声音默认关闭，可在顶部声音设置中分别开启音乐和音效；伙伴对话使用本地预设台词，不是联网 AI。

### 保存你的小店

进度自动保存在**当前浏览器、当前网址**中，没有账号或云同步。

在「收藏 → 小店档案袋」可以**导出进度备份**或**导入进度备份**。换浏览器、换设备、换网址或清理浏览器数据前，请先导出，并确认备份文件确实保存。导入会替换当前进度，请先备份。

如果你以前在 `http://127.0.0.1:8765/` 或本地 HTML 中玩过，请从原入口导出，再到上面的在线版导入；不同入口不会自动共享存档。

### 需要安装 Python 或启动服务器吗？

**不需要。点击上面的链接，就能在浏览器里玩。** 在线版由 GitHub Pages 托管，不依赖你的手机保持任何后台进程。

项目是 HTML、CSS、JavaScript 和 SVG 组成的静态网页，没有 Python 后端。仓库里的 `build-local.py` 只是开发时使用的可选打包脚本：把样式、脚本和图片内嵌到一个 HTML 文件中，方便离线使用。它不会启动服务器，玩家也不需要运行它。

### 可选：离线游玩

下载仓库中的 [梦境织补屋-直接打开.html](梦境织补屋-直接打开.html)，用支持 JavaScript 的浏览器打开，而不是仅用文件预览器。下载时请保存 HTML 文件本身，而不是 GitHub 的文件展示页面。

离线版不需要 Python 或本地服务器。不同浏览器对本地文件、下载、导入及存储的支持可能不同；移动文件或更换打开方式前也请备份。在线版与离线版的进度不会自动同步。
